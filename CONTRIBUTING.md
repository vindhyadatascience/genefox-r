# Contributing

Please file issues and pull requests at https://github.com/vindhyadatascience/genefox-r.

This repository is the public distribution of the GeneFox r package.
Development and cross-platform runtime verification are coordinated in GeneFox's
private development repository. Maintainers bring reviewed public contributions
back to that source and regenerate the public snapshot; edits are not overwritten
silently. `genefox-source.json` identifies the originating commit and every file.

The GeneFox engine and native runtime are proprietary and supplied separately.
Contributions here cover the permissively licensed package, not the engine.
